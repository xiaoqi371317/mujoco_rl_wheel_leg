# 结果、失败与经验

本页记录此次项目整理前的实验结果，原始统计经路径脱敏后收录于 `reports/`。没有把最后一个检查点自动称为最好。

## 主要结果

- V5 行进基线：运动评估曾通过 26/42；低姿静止长窗口轮子前后错位约 8.6 cm，偏航约 0.064 rad/s。
- 单纯强化跳高的 V6：同类运动验收从 26/42 降至 15/42，站姿也变差。失败方案未列为推荐检查点。
- 专项站姿修正：低姿错位降至约 0.72 mm、偏航约 0.0063 rad/s，但高姿制动仍失败，运动验收降至 20/42。单一指标改善不等于整体变好。
- 气弹簧适应 200 轮：动态 9/32；200 N 静止 2/4，300 N 静止 0/4。
- 落地时序续训 300 轮：匹配相同新时序的对照从 9/32 变为 8/32。新增 1.5 m/s 指令跳跃的部分通过项，同时丢失若干静止和制动项，详见 comparison.json。
- 最新模型在 200 / 300 N、1.5 m/s 指令跳跃中，分别达到约 17.6 / 19.0 cm 轮子净空，对应最低阶段保速约 81.5% / 83.9%，各 4 次通过。这里是指令速度，实际起跳速度见报告；不是实物越障高度。
- 最新 200 N 和 300 N 长时站姿均为 0/4。即使低姿错位仅约 2.37 / 0.63 mm，速度与高度误差仍超标。1.0 m/s 跳跃存活 3/4 也不满足完整保速门槛。

动态 32 项是速度/动作与四档气弹簧力的组合，每项有重复试验；站姿 4 项是四种状态，每项同样有重复。不同试验协议的数字不能直接横向排名。

## 值得复用的教训

1. **先排除模型问题，再诊断策略。** 镜像惯量、关节轴和闭链姿态要一起检查；视觉上惯量椭球不对称本身不是完整证据。对称模型上策略仍可能学出分叉。
2. **奖励名称也会导致逻辑错误。** 继承任务时同名 `braking` 覆盖了原来的静止偏航惩罚，导致制动/跳跃奖励替换了站立约束。静止偏航项应使用独立的 `stand_yaw_stop`。
3. **跟踪容差不能兼任静止标准。** 0.35 rad/s 的转向容差对静止太宽松。长时站姿需要航向漂移、速度、高度、两腿错位的联合门槛。
4. **跳高目标要对应真实需求。** 目标是收腿提高轮子净空，并保持起跳前速度，不只是抬高车身。分别测量轮子净空、车体上升和机体到轮子距离。
5. **腾空收腿与落地伸腿不能同时奖励。** 旧逻辑在准备落地时仍奖励收腿。改用预计触地时间触发伸展，并关闭冲突项；但这种修改仍需要静止与行驶回归测试。
6. **弹簧不是免费能量。** 恒定拉力可帮助蹬地、减轻部分电机负载，也可能抵抗收腿。必须区分附加拉力 N 与关节力矩 Nm，不能混算损失。
7. **续训会遗忘。** 保留 Adam 和 teacher 并不保证站立技能保留。检查点选择应以多技能验收门槛为准，不能按最新迭代或平均奖励选。
8. **指标要有有效样本数。** 只在某阶段统计的指标应报告该阶段采样数量；摔倒后没有样本时的零值不是完美表现。
9. **核对实际加载文件。** 旧选择器曾退回旧检查点，造成“新目录回放旧策略”。明确传 `--checkpoint` 并打印路径。
10. **地形细化有计算代价。** 过密 heightfield 曾导致接触候选溢出；调网格间距后还需复测，不能把仿真异常当作策略失败。

## 下一步建议（尚未实现）

保留已经验证的站立/移动能力，再对跳跃阶段做隔离优化；可以比较单策略加回放数据与独立专家切换，但切换连续性同样需要测试。先获取实物气弹簧推力—行程和安装几何，再做参数随机化。每轮同时验收静止、制动、行驶、原地跳和行进跳，最后才加入真实障碍几何。

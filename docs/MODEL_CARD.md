# 模型与检查点

## 机器人与策略接口

左右对称修正入口为 `training_scene_fix.xml`；气弹簧实验使用 `training_scene_fix_gas_trial.xml`。总质量约 18.705 kg，车体约 14.528 kg，轮半径 0.06 m。模型包含闭链约束，复位使用 `v5_poses.json` 中的相容姿态，不能对每个关节独立随机化后假定闭链仍成立。

策略观测 56 维，动作 6 维。实际驱动顺序为 rf0、lf0、r20、l20、右轮、左轮；腿部采用参考姿态叠加残差与 PD，残差幅度 0.35 rad、Kp=240、Kd=8、力矩上限 30 Nm。左右轮动作缩放符号分别为 -8 和 +8 Nm。不要根据另一处关节列表顺序猜测接口。

仿真步长 0.002 s，控制 decimation=10，即 50 Hz。阶段依次是行驶/静止、起立、下蹲、蹬地、腾空、落地。GUI 正向为模型 -X。气弹簧模型多出两个物理执行器，但仍只有 6 维策略动作；附加执行器单位是 N，不能并入力矩 Nm 的惩罚统计。

对称修正针对质量、惯量和运动学，已有多姿态诊断；不意味着每个碰撞网格和实物制造误差都经过标定。相关报告见 `reports/symmetry_fix_validation.json`。

## 预训练包

| 目录 | 检查点 | 用途与限制 |
|---|---|---|
| v5_motion | model_3250.pt | 推荐先体验的无气弹簧移动/跳跃基线；静止分叉和漂移仍存在 |
| gas_adapt | model_3449.pt | 200 轮气弹簧适应后的中间状态，用作落地实验 teacher/source |
| gas_landing | model_3748.pt | 再续训 300 轮，改进部分行进跳跃，静止验收退化 |

检查点保留 actor、critic、Adam、迭代编号，移除了 `infos` 中潜在私有元数据。`run.json` 的 source/teacher 绝对路径已移除；其中 `source_sha256` / `teacher_sha256` 是**历史原始检查点**哈希，不是脱敏后文件哈希。当前公开文件以根目录 `SHA256SUMS.json` 为准。运行时源码哈希与物理 XML 哈希保留用于兼容检查。

气弹簧是沿安装点作用的恒定拉力近似，不是经实测的气体热力学/摩擦/压力模型。实物确认有气弹簧，但推力、行程和安装曲线未提供；200–300 N 训练范围为实验假设。100 N 回放属于训练力范围外测试。模型不能直接作为实物部署参数。

仅报告仿真结果；没有实物验证，也没有证明可以跨过指定高度障碍。保速跳跃与跨障碍成功是不同的验收任务。
